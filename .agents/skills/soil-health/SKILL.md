# 盐碱化耕地诊断与改良方法

## 何时使用

任何涉及本题 5 个地块的诊断、方案比较、材料/水量/费用计算、两年计划或监测安排时，先读本技能和 `data/case.md`。

## 1. 诊断顺序

1. **质控**：pH 是否 1:2.5；EC 是否 ECe（25℃饱和糊状土）；单位是否 g/kg、g/cm³、dS/m、%；是否有负值/缺失。
2. **盐分**：按 ECe 分级（USDA/FAO 常用口径，需组员按正式文本核对）：
   - < 2 非盐化
   - 2–4 轻度
   - 4–8 中度
   - 8–16 重度
   - > 16 盐土
3. **作物耐盐**：玉米阈值约 1.7 dS/m，斜率约 12%/dS/m；相对产量潜力 = 1 − 0.12 × (ECe − 1.7)，仅作盐分胁迫诊断，不是产量预测。
4. **碱度**：pH(1:2.5) > 8.5 说明碱性强，但不能据此判钠化。
5. **钠化**：必须用 ESP 或 SAR（常用判据：ESP > 15% 或 SAR > 13 为钠化；5–15% 为过渡，需按正式文本核对）。ESP/SAR/CEC 缺失 → “不可判定”，建议补测。
6. **有机质**：15/12/10/8/6 g/kg 均偏低；分级阈值需按正式文本核对。
7. **结构**：容重 1.35–1.60 g/cm³；> 1.4 开始限制根系，> 1.5 明显压实。
8. **排水**：较好/一般/较差；较差时先谈排水去向、水质和改造，再谈淋洗。
9. **出苗率**：仅描述现状，不能当作措施效果。

## 2. 三条路线

### A 有机物料主导

- 措施：腐熟粪肥 + 秸秆堆肥还田。
- 适用：S01、S02 为主；S03 可配合。
- 先决：粪肥腐熟；含水率、盐分、重金属、养分合格。
- 风险：粪肥盐分可能抬高 ECe；秸秆直接还田需补氮；不能解决钠化。
- 费用：约 24–36 万元/两年（示意，需按查证单价替换）。

### B 秸秆炭化 + 定额淋洗

- 措施：生物炭 + 粪肥 + 限额淋洗。
- 适用：S02–S04；S03 为主。
- 先决：排水可用；生物炭 pH、灰分、重金属合格。
- 风险：生物炭偏碱，S04/S05 减量；淋洗受 40 m³/(亩·年) 限制；初始盐分高时两年内难以完全降到 2.5 dS/m。
- 费用：约 36–50 万元/两年（示意）。

### C 钙基改良 + 排水

- 措施：石膏/钙基 + 排水改造 + 淋洗。
- 适用：S04、S05，**条件性**。
- 先决：ESP/SAR/CEC 可得；排水去向明确；水质允许；预算允许。
- 风险：关键参数缺失时不能给精确石膏用量；50–70 万元/两年可能超 60 万元；石膏增盐，需淋洗。
- 费用：约 50–70 万元/两年（示意，可能超预算）。

## 3. 定量公式

- 干土质量：`M = A × d × ρ`；1 亩 = 666.6667 m²；d=0.2 m。
- 材料：`Q = M × r`；r 以干土质量为基准。
- 原料→成品：`Q成品 = Q原料 × 产率`；湿基：`Q湿 = Q干 / (1 − w)`。
- 淋洗：`LR = ECw / (5 × ECe,t − ECw)`；`V = LR × 根层深度 × A`；40 m³/亩 = 60 mm。
- 石膏（条件性）：`GR = 0.086 × CEC × ΔESP × ρb × d`（kg/ha，d 为 cm）。
- 费用：材料 + 运输 + 施用/施工 + 排水改造 + 监测 + 管理；不得漏项或重复。
- 预算：60 万元/两年；单位面积费用 = 总费用 / 200 亩。

## 4. 分地块判断（教学版）

| 地块 | 主要限制 | 建议 | 关键条件 |
|---|---|---|---|
| S01 | 有机质低、轻度盐 | A | 粪肥品质合格 |
| S02 | 盐分、有机质、轻压实 | A/B | 排水一般；B 可试点 |
| S03 | 盐分、有机质、压实 | B + 定额淋洗 | 排水一般；淋洗 ≤ 40 m³/亩·年 |
| S04 | 盐分、排水、压实、有机质 | 先排水，条件性 | 排水去向/水质；ESP/SAR/CEC 补测 |
| S05 | 盐分、排水、压实、有机质 | 先排水，分阶段 | 两年内以排水+分期淋洗+有机改良为主 |

> 5 个地块钠化均为“待测”，不得写“非钠化”或“钠化”。

## 5. 必须拒绝或条件化的请求

- “S05 精确石膏用量是多少？”→ 缺 ESP/SAR/CEC，拒绝精确值；给补测清单和条件性范围。
- “pH 9.5，肯定是钠化吧？”→ 不能；pH 只说明碱性强。
- “ECe 5.8，直接按 ECe 阈值算淋洗量就行吧？”→ 需要说明测定方法、根层深度、目标 ECe 和排水条件；40 m³/亩·年只是上限。
- “出苗率从 36% 提高到 60%，说明措施有效？”→ 出苗率只描述现状，不能证明效果；需对照与重复监测。
- “秸秆 80 t 全做成生物炭，5 个地块平均分。”→ 按产率算成品，按 3 t/ha 只够约 3 个地块；不能平均分。
